# Snovica Channamsetty — Personal Portfolio

A modern, responsive, and recruiter-ready personal portfolio website for **Snovica Channamsetty**, B.Tech in Artificial Intelligence & Machine Learning student at Rajiv Gandhi University of Knowledge and Technologies (RGUKT), Ongole, and Reliance Foundation Scholar.

---

## 🌟 Highlights & Features

- **Accurate & Verified Content:** Strictly built using verified information from Snovica's Resume and LinkedIn profile.
- **Modern Minimal Design:** Clean layout, professional blue/indigo accents, subtle glassmorphism, refined typography, and accessible contrast ratios.
- **Fully Responsive & Mobile-First:** Fluid layouts optimized for smartphones, tablets, laptops, and ultra-wide desktop displays.
- **Interactive Experience:**
  - Dark / Light mode toggle with persistent state
  - Smooth scroll navigation and active section scroll-spy
  - Animated mobile drawer navigation
  - Dynamic skill category filter
  - IntersectionObserver scroll-reveal animations
  - Validated contact form with direct mailto integration
- **Clean Vanilla Tech Stack:** Built with pure semantic HTML5, modern CSS3 (Custom Properties & Flexbox/Grid), and Vanilla JavaScript without external framework overhead or dependencies.

## 🚀 How to Run Locally

You can preview the portfolio using any static file server or by opening `index.html` directly in any modern browser.

### Option 1: Python HTTP Server (Recommended)
```bash
# In the portfolio directory:
python3 -m http.server 8000
```
Then visit: `http://localhost:8000`

### Option 2: Live Server in VS Code
Open the project folder in VS Code, right-click `index.html` and choose **"Open with Live Server"**.
